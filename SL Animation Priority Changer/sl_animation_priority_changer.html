Priority editing for .anim files

SL Animation Priority Changer

Drop animations in, see the priority they have now, pick a new one - for a single file or for all at once. When two animations play at the same time, the one with the higher number wins.

How does it work?

Every animation carries a priority from 0 to 6. If two animations move the same body part at the same time, the one with the higher number is the one you see. A dance at priority 4 will override a standing pose at 2, and a hand pose at 5 overrides both.

Drop your files in and the table shows what each one currently uses. Pick a new number per file, or use Set all to when a whole folder should share one priority. Files you changed are marked, then Export writes them out.

The exported file is identical to the original except for the priority numbers - all keyframes stay untouched. Everything happens on your computer, nothing is uploaded.
